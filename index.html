老師專區（需要密碼）

學生不用密碼：請學生點上面的「我是學生」，或直接掃教室的 QR Code 進來。

一、開一間教室

尚未建立教室。

教室代碼（學生輸入這個號碼就能進來）

學生也可以掃 QR Code 直接進教室，不用打代碼。

二、收到的答案（0 則）

按「投影播放」後，用鍵盤 ← → 或點按鈕翻頁，第一頁是問題，後面一頁一則答案。清除只是清掉這個畫面，雲端表格仍留有完整紀錄。

還沒有答案。學生送出後，幾秒內會自動出現在這裡。

三、歷史紀錄（把以前的答案叫回來）

每一堂課的問題和答案都存在雲端，這裡會照「提問日期時間＋問題」一筆一筆列出來。點「叫出這次答案」，那一次的答案就會回到上面的答案牆，可以再投影播放，也可以再下載儲存。
